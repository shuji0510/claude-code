# Gmail 返信テンプレプロンプト集（15種）

すべて Gemini in Gmail の「Help me write」または callGemini() にそのまま貼れる形式です。
`{...}` の部分は状況に合わせて書き換えてください。

---

## 1. 日程調整（候補日3つ提示）
```
以下のメールに、丁寧な口調で返信を作成してください。
・冒頭で日程調整のご連絡をいただいたことにお礼
・こちらの候補日を3つ提示（{候補日1} / {候補日2} / {候補日3}、いずれも90分想定）
・オンライン(Google Meet)前提、URLは追って送付する旨
・末尾に「よろしくお願いいたします」
【元メール】
{受信メール本文}
```

## 2. 見積書送付のお礼＋次回打ち合わせ提案
```
下記の見積確認メールへの返信を作成してください。
・見積書ご確認への感謝
・不明点があれば遠慮なく質問いただきたい旨
・意思決定に向けて、次回30分の打ち合わせを提案（今週後半で3案）
【元メール】
{受信メール本文}
```

## 3. 資料請求への返信（自動応答風）
```
資料請求フォーム経由の問い合わせメールへ、以下要件で返信を作成:
・お礼＋資料PDFを添付する旨（添付は別途こちらで行う想定）
・追加でヒアリングしたい3点（現状の課題、導入希望時期、想定利用人数）
・返信をもらえると次のアクションに移れる旨
```

## 4. 打合せキャンセルのお願い
```
以下条件で丁寧に打合せキャンセルの依頼メールへの返信を作成:
・キャンセル理由（社内緊急対応）を簡潔に共有
・代替候補日を3つ提示
・相手にご迷惑をおかけしたことへのお詫び
【元メール】
{受信メール本文}
```

## 5. クレーム一次対応
```
以下のクレームメールに対し、以下の順で返信文を作成:
1. まず率直なお詫び
2. 事実確認のため、必要な情報を最大3項目リストアップ
3. 恒久対策について社内で協議し、〇営業日以内にご回答する約束
4. 締めに再度のお詫びと、担当窓口の直通番号
【元メール】
{クレーム本文}
```

## 6. 支払いリマインド（BtoB, 温度低め）
```
未入金のリマインドメールを、以下の条件で作成:
・入金予定日を過ぎている件を穏やかに指摘
・行き違いの可能性への配慮
・支払期日と請求書番号を明記
・入金確認後の連絡ももらえると助かる旨
・末尾に担当連絡先
```

## 7. 求人応募者への一次通過連絡
```
求人応募者への一次書類選考通過メール:
・応募御礼
・通過のお知らせ
・次のステップ（オンライン一次面接、45分）
・候補日を3つ提示（{候補日}）
・面接官の役職と名前
・準備してきていただきたいこと2点
```

## 8. 顧客への価格改定案内
```
既存顧客への価格改定通知メール:
・改定の背景（原材料/人件費/機能拡張のいずれか）
・新価格と適用日
・既存契約者向けの経過措置（3ヶ月間旧価格 等）
・不明点は担当までとお問い合わせ窓口
・お詫びと今後もご愛顧をお願いする言葉
```

## 9. お礼メール（商談後・当日中）
```
本日商談した{相手会社名}様へのお礼メール:
・時間を頂戴したことへの感謝
・議論の中で印象的だったポイント3つを簡潔に振り返り
・次のアクション（提案書送付/PoC設計 等）と期日
・カジュアル過ぎず、堅すぎない温度感
```

## 10. 断りメール（相手の面子を保つ）
```
以下の提案メールに対し、丁寧にお断りする返信を作成:
・提案いただいたことへの感謝
・今回は見送る理由を1つだけ、正直に簡潔に
・将来的な可能性を残す一文
・関係を今後も継続したい旨
【元メール】
{受信メール本文}
```

## 11. 上司への進捗報告(社内向け、簡潔)
```
上司への進捗報告メールを作成:
・件名は【進捗】案件名 で始める
・冒頭1行で状況(順調/一部遅延/要相談)
・箇条書きで進捗3点 / 課題2点 / 次アクション2点
・返信不要 or 判断依頼 かを最後に明記
```

## 12. 社内アナウンス（新機能リリース）
```
社内向け新機能リリースアナウンスメール:
・タイトル：【リリース】機能名
・何が / いつから / 誰に嬉しいのか、を各1行で
・使い方は社内Wikiリンクに誘導
・問合せ先とリリース責任者名
```

## 13. 会食お誘いメール
```
{相手会社名}様との会食お誘いメールを作成:
・きっかけになる話題（先日の商談/新プロジェクト）
・カジュアルなお誘いのトーン
・候補日を平日夜で3つ
・エリアの候補を2つ
・当方参加者を明記
```

## 14. 忘年会/新年会案内
```
社内向け忘年会案内メール:
・日時・会場・会費・出欠回答期限
・カジュアルで参加ハードルを下げるトーン
・幹事の連絡先
・「途中参加/途中退出OK」の一言
```

## 15. 退職挨拶メール
```
社外向け退職挨拶メール:
・退職日と最終出社日
・お世話になったお礼（具体エピソード1つ）
・後任担当者と引継ぎ状況
・個人連絡先（希望者のみ）
・締めに今後の変わらぬご厚誼をお願いする言葉
```
