# スプレッドシート × Gemini 分析プロンプト集（20種）

Google スプレッドシートのサイドパネル Gemini、または `=GEMINI("...")` にそのまま貼れます。

---

## 集計・整形（1〜7）

### 1. 月別売上サマリ
```
このシートの売上データから、月別合計・平均・前月比を表形式でまとめ、
別シート「月別サマリ」に出力してください。
```

### 2. 顧客ランキング
```
顧客別売上ランキング TOP10 を新シート「TOP顧客」に出力し、
上位3社は背景色を薄い黄色で強調してください。
```

### 3. 特定条件で抽出
```
シート「顧客リスト」から、所在地が東京都かつ従業員数100名以上の行だけを、
新シート「重点顧客」にコピーしてください。
```

### 4. 重複削除
```
A列のメールアドレスの重複を検出し、重複行はまとめて背景色をグレーにしてください。
残す1行はいちばん新しい登録日のものにしてください。
```

### 5. 日付から曜日・週番号を追加
```
A列の日付をもとに、B列に曜日、C列に週番号(ISO形式)を関数で追加してください。
数式で書いてください（値貼り付けではなく）。
```

### 6. 全角/半角/敬称の正規化
```
「顧客名」列の敬称（様/御中/株式会社などの表記ゆれ）を正規化し、
別列に「正規化後」を出力してください。
```

### 7. カテゴリ分類
```
「商品名」列を、以下カテゴリに自動分類してください。
カテゴリ: [ハード, ソフト, サービス, その他]
結果を「カテゴリ」列に書き込んでください。
```

## 可視化（8〜12）

### 8. 折れ線グラフ
```
月別売上を折れ線グラフで表示。X軸は月、Y軸は円、
系列は「商品カテゴリ」ごとに色分けしてください。
```

### 9. 積み上げ棒グラフ
```
四半期別売上を、事業部別の積み上げ棒グラフに。
凡例は右側、データラベルは合計値のみ表示してください。
```

### 10. パイチャート（構成比）
```
顧客業種別売上構成比をパイチャートで表示。
5%未満のセグメントは「その他」にまとめてください。
```

### 11. ヒートマップ
```
曜日×時間帯の問い合わせ件数をヒートマップで色付けしてください。
値が大きいセルを濃い赤、小さいセルを薄い青にしてください。
```

### 12. 散布図＋回帰直線
```
広告費(A列)と売上(B列)の散布図を作成。
回帰直線と決定係数(R²)を表示してください。
```

## 分析コメント生成（13〜17）

### 13. 前月比コメント自動生成
```
=GEMINI("次の数値を3行以内で分析コメント化: 前月売上=" & B2 & " 今月売上=" & B3)
```

### 14. 異常値検出
```
売上シートを全体的にチェックし、平均±2σを超える異常値を検出。
発生日・顧客・要因の推測を新シート「異常値レポート」にまとめてください。
```

### 15. 顧客セグメンテーション
```
顧客リストを RFM(Recency/Frequency/Monetary) で3セグメントに自動分類し、
各セグメントの人数・平均単価・推奨施策を出力してください。
```

### 16. コホート分析
```
初回購入月別に、その後6ヶ月のリピート率をコホート表で表示してください。
```

### 17. 定性フィードバックの分類
```
「アンケート自由記述」列の内容を、
[品質/価格/納期/接客/その他] に分類し、件数を横棒グラフに。
```

## 数式・関数の代替（18〜20）

### 18. VLOOKUP代替
```
=GEMINI("次の顧客IDに対応する会社名を教えて。参照リスト: " & JOIN(",", Sheet2!A2:B) & " ID: " & A2)
```
※ 少量データ向け。大量データは QUERY / XLOOKUP を推奨。

### 19. 自由記述の要約列
```
=GEMINI("次を30字以内で要約: " & C2)
```

### 20. 感情スコア
```
=GEMINI_CLASSIFY(D2, "ポジティブ,ネガティブ,ニュートラル")
```
→ ネガティブ行をフィルタで洗い出す運用がオススメ
