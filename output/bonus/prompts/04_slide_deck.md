# スライド構成テンプレプロンプト集（10種）

Google AI Studio または `slides_generator.gs` の入力として使えます。
`{...}` は自社/自案件の内容に書き換えてください。

---

## 1. 提案書（BtoB営業・標準10枚）
```
以下条件で10ページのプレゼン構成を作成。各ページは title/body/notes を持つ JSON 配列で。

# テーマ
{顧客名}様向け {サービス名} 導入提案書

# 構成
1. 表紙
2. 本日のアジェンダ
3. 貴社の現状課題（仮説3点）
4. 課題を放置したときのインパクト
5. 解決策のコンセプト
6. 具体的な機能・仕様
7. 導入事例（同業界1社）
8. 導入スケジュール（3ヶ月モデル）
9. 費用感（初期＋月額）
10. 次のアクション

# 条件
- ターゲット: {役職・年代}
- 各ページ本文は箇条書き3〜5点
- スピーカーノートは150字以内
- 数値は必ず出典を明記
```

## 2. 社内報告書（月次）
```
以下テーマで8ページの月次報告資料を作成。
テーマ: 2026年3月度 {部署名} 業績報告

構成:
1. 表紙
2. サマリー(3行)
3. KPIダッシュボード(数字)
4. 好調要因(TOP3)
5. 苦戦要因(TOP3)
6. 打ち手一覧(今月実施 & 来月予定)
7. 依頼事項(他部署への)
8. 質疑応答用データ集

条件:
- 数値には前月比・前年比を必ず付ける
- スピーカーノートに「上司から想定される質問」を1件ずつ追加
```

## 3. 研修資料（60分・15枚）
```
以下テーマで15ページの研修資料構成を作成。
テーマ: 新入社員向け「ビジネスメールの書き方」60分研修

構成:
- 導入(2枚): 研修ゴール / アイスブレイク問い
- 基礎(5枚): 件名/敬語/構成/署名/よくあるNG
- 実践(5枚): ケーススタディ5本(依頼/断り/謝罪/日程調整/報告)
- 応用(2枚): テンプレ集の紹介
- まとめ(1枚): 今日のTakeaway 3点

条件:
- 各スライドに5分以内で説明できる分量
- ワーク(参加者に手を動かしてもらう時間)を必ず2箇所埋め込む
- スピーカーノートに「タイマー案内」を含める
```

## 4. IR説明会（投資家向け・15枚）
```
以下テーマで15ページのIR説明会スライドを作成。
テーマ: 2026年3月期通期決算説明会

構成:
1. 表紙
2. サマリー
3-5. 通期業績（PL/BS/CF）
6. セグメント別業績
7. 主要KPIの推移
8-10. 中期経営計画進捗
11. 新事業ハイライト
12. リスク要因と対応
13-14. 次期業績予想
15. 株主還元方針

条件:
- 数値は単位・比較対象を必ず明記
- 断定表現を避け「見込み」「想定」を使う
- 前提条件の注記スライドを追加
```

## 5. ピッチデック（スタートアップ・10枚）
```
以下テーマで10ページのピッチデック構成を作成。
テーマ: {事業名} シリーズA資金調達用ピッチ

構成:
1. タイトル(会社/One-liner)
2. 課題(Pain)
3. 解決策(Solution)
4. プロダクトデモ
5. 市場規模(TAM/SAM/SOM)
6. ビジネスモデル
7. トラクション(実績数値)
8. 競合比較
9. チーム
10. Ask(調達額・使途)

条件:
- 各スライドは "1メッセージ" 原則
- 数字は必ず出典/前提を明記
- Ask スライドは投資家目線で "リターン" が想像できる内容に
```

## 6. カンファレンス登壇（20枚・30分）
```
テーマ: {テーマ名} - 実例で学ぶ〇〇の始め方
時間: 30分 / 質疑応答は別途10分

構成:
1. 自己紹介
2. 今日の1メッセージ
3-5. なぜ今このテーマか(市場背景)
6-10. ケーススタディ1(失敗事例)
11-15. ケーススタディ2(成功事例)
16-18. 明日から始める3ステップ
19. まとめ
20. 質疑応答へ

条件:
- ストーリーテリング重視
- 数字は最小限
- 各章の冒頭に「問い」を配置
```

## 7. サービス紹介資料（外部配布・営業非同席）
```
テーマ: {サービス名} サービス紹介資料 v2026.04

構成:
1. 表紙(スペックだけでなくビジョンを1行)
2. こんな課題ありませんか?(共感)
3. 私たちの解決策
4. 3つの特徴
5. 導入企業ロゴ
6. 導入事例(ロゴ→数値→顧客の声)
7. サービス機能一覧
8. 料金プラン
9. 導入までの流れ(1-2-3)
10. FAQ 5選
11. 無料相談CTA

条件:
- 営業がいなくても伝わる自己完結型
- CTAへの導線を各章に1つ埋め込む
- テキストは箇条書き中心
```

## 8. 社内キックオフ（プロジェクト開始）
```
テーマ: プロジェクト "{プロジェクト名}" キックオフ

構成:
1. 表紙
2. 背景・なぜやるのか
3. ゴール(北極星指標)
4. スコープ(やる/やらない)
5. マイルストーン(4半期別)
6. 体制図(Who)
7. 意思決定フロー
8. コミュニケーションルール
9. 使用ツール一覧
10. 質問・懸念ラウンドテーブル

条件:
- 参加者のロールを冒頭で明示
- "なぜ" に3枚投資
- スピーカーノートに "ここで拍手" 等の運営メモ
```

## 10. ワークショップ設計資料（社内AI導入・90分）
```
テーマ: 全社員向け「生成AI活用ワークショップ」90分

構成:
1. 表紙 & ゴール共有
2. アイスブレイク(5分)
3. 生成AIとは(10分)
4. デモ1: メール返信(10分)
5. ワーク1: 実際に返信を作る(15分)
6. デモ2: スプレッドシート分析(10分)
7. ワーク2: 自部署のデータで試す(20分)
8. 明日から続ける仕組み化(10分)
9. まとめ & 質疑応答(10分)

条件:
- 各章にワーク or デモを必ず埋め込む
- スピーカーノートに時間配分を明記
- ハンズオン用の配布URL欄を用意
```
