# 議事録テンプレプロンプト集（5種）

NotebookLM または Gemini in Docs に、文字起こしと一緒に貼り付けてご利用ください。
「決定 / ToDo / 担当 / 期限」を必ず明示させるのが精度を上げるコツです。

---

## 1. 汎用議事録テンプレ（社内定例）
```
以下の文字起こしから、フォーマットに従って議事録をまとめてください。

# フォーマット
## 会議概要
- 日時 / 出席者 / 目的

## 決定事項
| # | 内容 | 決定理由 |
|---|------|----------|

## ToDo
| # | 内容 | 担当者 | 期限 | 完了条件 |
|---|------|--------|------|----------|

## 議論の要点
- 箇条書きで最大5件

## 次回アジェンダ案
- 3件以内

# 条件
- 敬体で
- 話者名が不明な場合は「参加者A」等で表記
- 期限が明示されていない場合は「要相談」と記入
```

## 2. 顧客商談議事録
```
以下は顧客商談の文字起こしです。営業メンバー向けの引継ぎドキュメントとして議事録を作成。

## 商談概要
- 顧客企業 / 出席者(先方・当方) / 商談ステータス

## 顧客の課題（BANT整理）
- Budget(予算)
- Authority(決裁者)
- Need(ニーズの深さ)
- Timing(導入時期)

## こちらの提示内容
- 提案要旨 / 想定金額 / 差別化ポイント

## ネクストアクション
| # | 内容 | 担当 | 期限 |

## リスク / 懸念
- 3件以内

# 条件
- 商談の温度感を1〜5でスコアリング
- 想定失注リスクを一言で
```

## 3. 採用面接ふりかえり
```
以下は候補者との面接文字起こしです。人事評価用の議事録を作成。

## 候補者情報
- 氏名 / 応募ポジション / 面接官

## 評価サマリー
- 総合スコア (1-5) と一言コメント

## 強み / 弱み
| カテゴリ | 内容 |
|----------|------|
| 強み | |
| 弱み | |

## スキル評価
- 技術力 (1-5)
- コミュニケーション (1-5)
- カルチャーフィット (1-5)

## 次のアクション
- 次選考へ進めるか / 見送りか
- 進める場合の次選考課題

# 条件
- 主観と客観事実を分けて記述
- 差別的な表現を含めない
```

## 4. 経営会議・取締役会議事録
```
以下は経営会議の文字起こしです。正式議事録として作成してください。

## 開催概要
- 日時 / 出席役員 / 議長 / 書記

## 議案
### 議案1: {タイトル}
- 提案者 / 背景 / 議論の要点 / 決議結果 / 賛否数

### 議案2: ...
（以降同様）

## 決議事項一覧
| # | 議案 | 決議結果 | 実行責任者 | 期限 |

## その他報告
- 3件以内

# 条件
- 公文書調（である体）
- 発言者の名前は必ず明記
- 数値・金額は必ず単位付き
```

## 5. 議事録→Slack/Chat投稿用サマリ
```
以下の議事録を、Slack投稿用に150字以内で要約してください。

# 出力形式
📝 {会議名} まとめ
✅ 決定: {最大2件、絵文字なし}
📌 ToDo: {重要ToDo最大3件、@担当者付き}
📅 次回: {次回開催日 or 次アクション期日}

# 条件
- 敬語ではなくフラットな社内トーンで
- 内部リンクや詳細URLは残す
- 150字を超える場合は「（続きは議事録参照）」で締める
```
