# Fable 5 リライトスキル

渡された文章(ファイルパスまたは本文)を、`fable5-writing` スキルの原則に沿って書き直す。

## 手順

1. まず `.claude/skills/fable5-writing/SKILL.md` を読み込み、原則を把握する。
2. 対象文章を読み、以下を診断する:
   - 結論が先頭にあるか。埋もれていれば先頭に引き上げる。
   - 矢印チェーン・断片文・未定義の略語を、完全な文に展開する。
   - 「案 B」「前述の問題」のような参照ラベルを、その場の言い直しに置き換える。
   - 不要な見出し・表・箇条書きを文章に戻す。逆に、列挙可能な事実の羅列は表にしてよい。
   - 読者の次の行動を変えない詳細を削る。
3. リライト結果を提示する。元ファイルの上書きは、ユーザーが明示的に求めた場合のみ行う。
4. 変更点の要約を 2〜3 文で添える(何を先頭に出したか、何を削ったか)。

## 注意

- 意味・事実関係は変えない。文体と構造だけを直す。
- 技術用語を不正確な平易語に置き換えない。用語は残し、必要なら一言の説明を足す。
- 元の言語を維持する(日本語は日本語のまま、英語は英語のまま)。
