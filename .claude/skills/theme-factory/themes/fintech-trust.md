# Fintech Trust

A quiet, confidence-building fintech theme. Deep ink backgrounds with a single
restrained blue accent and tabular-friendly mono pairing — designed for
dashboards, reports, and customer-facing financial surfaces where readability,
trust, and gravitas matter more than visual flair.

## Color Palette

### Surfaces
- **Ink**: `#0B1220` - Page background (almost-black blue)
- **Slate 900**: `#0F172A` - Primary surface
- **Slate 800**: `#1E293B` - Elevated cards / nav
- **Slate 700**: `#334155` - Borders, dividers, hairlines

### Text
- **Cloud**: `#F8FAFC` - Primary text on dark
- **Mist**: `#CBD5E1` - Body / secondary text
- **Ash**: `#94A3B8` - Muted text, captions
- **Steel**: `#475569` - Disabled / placeholder

### Accent
- **Trust Blue**: `#3B82F6` - Primary accent (CTAs, focus rings, links)
- **Trust Blue Hover**: `#2563EB` - Pressed / hover state
- **Trust Blue Soft**: `#1D4ED8` - Selected / dark fills

### Semantic (muted, not loud)
- **Gain**: `#10B981` - Positive numbers, success
- **Loss**: `#EF4444` - Negative numbers, error
- **Caution**: `#F59E0B` - Warning, pending
- **Info**: `#38BDF8` - Informational

## Typography

- **Headers**: Inter (Tight, weight 600/700)
- **Body Text**: Inter (Regular 400 / Medium 500)
- **Numerics / Tabular**: JetBrains Mono (Regular 400) — for tables, KPIs,
  account numbers, amounts. Use `font-feature-settings: "tnum", "lnum"`.

Fallback stack: `Inter, ui-sans-serif, system-ui, -apple-system, "Segoe UI",
Roboto, sans-serif`.

## Spacing & Radii

- **Radius**: 6px (sm), 10px (md), 14px (lg), 999px (pill for tag chips)
- **Hairline border**: 1px solid `#334155`
- **Focus ring**: 2px `#3B82F6` + 2px offset on `#0B1220`

## Best Used For

Banking dashboards, brokerage UIs, treasury / spend management consoles,
quarterly investor reports, fintech landing pages targeting enterprise
buyers — anywhere "calm authority" beats "exciting growth".
