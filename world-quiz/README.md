# 🌍 世界の国と首都マスター

中学1年生の社会「世界地図確認プリント」（60か国）の**国名・首都・場所**を、
ゲーム感覚で覚えるためのWebアプリです。

## つかいかた

`world-quiz/index.html` をブラウザでひらくだけ。
インターネット接続もインストールも不要で、スマホ・タブレット・PCどれでも動きます。

```
# ローカルサーバーで開きたいときは（任意）
npx http-server world-quiz -o
```

## 6つのモード

| モード | ないよう |
| --- | --- |
| 🏙️ 首都あてクイズ | 国名を見て、首都を4つからえらぶ |
| 🏳️ 国あてクイズ | 首都を見て、国名を4つからえらぶ |
| 📍 場所あてクイズ | 国名を見て、地図の上をクリックしてさがす |
| 🔦 ここどこ？クイズ | 黄色く光っている国の名前をあてる |
| 🎲 ミックス | 上の4種類がランダムに出る |
| ⏱️ 60秒タイムアタック | 制限時間内に何問正解できるかに挑戦 |
| 📖 学習モード | 地図と一覧で、国・首都・位置・豆知識をかくにん |

## とくちょう

- **出す範囲をえらべる** … ぜんぶ（60か国）／アメリカ大陸／ヨーロッパ／アフリカ／西アジア・中央アジア／南・東アジア
- **問題数をえらべる** … 5問・10問・20問・ぜんぶ
- **にがて優先出題** … まちがえた国は、次から出やすくなる
- **まちがえた問題だけ復習** … 結果画面のボタンからすぐ再挑戦できる
- **地図はドラッグ・ホイール・ピンチで拡大縮小** … 小さい国は拡大ボタン（世界／アメリカ／ヨーロッパ／アフリカ／西アジア／東・南アジア）でジャンプ
- **とくてん・れんぞく正解・自己ベスト** … ブラウザに保存される（`localStorage`）
- **キーボード操作** … `1`〜`4` で選択、`Enter` で次の問題
- 効果音は右上の 🔊 ボタンでオン・オフ

## ファイル構成

| ファイル | 中身 |
| --- | --- |
| `index.html` | 画面の骨組み |
| `styles.css` | 見た目 |
| `data.js` | 60か国のデータ（番号・国名・首都・首都の緯度経度・豆知識） |
| `mapdata.js` | 世界地図の形（0.1度単位・差分エンコードで約32KB） |
| `app.js` | 地図の描画、当たり判定、クイズの進行 |

## 地図データについて

[Natural Earth](https://www.naturalearthdata.com/) の 1:110m Admin 0 Countries
（パブリックドメイン）をもとに、ダグラス・ポイカー法で簡略化して埋めこんでいます。
外部サーバーへの通信は一切ありません。

## メモ

- 国名・首都の表記は、学校のプリントに合わせています（例：ウクライナの首都は「キエフ」。近年は「キーウ」と書くことが多くなっています）。
- 地図は簡略化しているため、こまかい海岸線や小さな島は省略されています。
